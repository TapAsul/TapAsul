Put your client work photos in THIS folder.

Then list them in site.config.js under  myWork -> items :

    myWork: {
      items: [
        { image: "assets/work/kusina.jpg",
          title: "Kusina ni Maria",
          note: "Restaurant · Quezon City",
          href: "https://portal.tapasul.com/r/yourname" },
      ],
    },

Each picture becomes one tile in the "My work" section on the home page.
title, note and href are optional.
